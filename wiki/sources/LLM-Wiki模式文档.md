# LLM Wiki 模式文档

> 原文：[[llm-wiki|raw/llm-wiki.md]] —— 一份「idea file」，作者刻意保持抽象，只传达模式本身，具体实现交给读者与其 LLM Agent 协作实例化。本知识库即是它的一个实例。

## 核心主张

与 [[RAG]] 式的「查询时临时检索」不同，让 LLM **增量构建并持续维护一个持久的、互链的 markdown wiki**（见 [[LLM-Wiki模式]]）。知识被编译一次并保持最新，而不是每次提问都从头拼凑——wiki 是一个**复利资产**：交叉引用已就位、矛盾已标注、综合已反映读过的一切。

## 要点

- **三层架构**：raw 原始资料（不可变）/ wiki（LLM 全权维护）/ schema（约定文件）。详见 [[三层架构]]。
- **三种操作**：[[Ingest]]（摄入来源）、[[Query]]（查询并回填答案）、[[Lint]]（定期健康检查）。
- **两个导航文件**：内容导向的 index 与时间导向的 log。详见 [[索引与日志]]。
- **人机分工**：人负责选来源、提问、思考含义；LLM 负责摘要、交叉引用、归档等全部簿记。维护成本趋近于零——这正是人类 wiki 总被荒废而这里不会的原因。
- **工具生态**：[[Obsidian]] 作为浏览界面（图谱、Web Clipper、Dataview、Marp）；规模变大后可引入 [[qmd]] 做本地搜索；wiki 本身就是 git 仓库，白得版本历史。
- **思想渊源**：Vannevar Bush 1945 年的 [[Memex]] 构想——私人、策展、以文档间关联为核心；Bush 没解决的「谁来维护」由 LLM 补上。

## 适用场景

个人成长记录、长期课题研究、读书伴读 wiki（类比 Tolkien Gateway 这样的粉丝 wiki）、团队内部 wiki、竞品分析、尽调、行程规划、课程笔记——一切「长期积累且希望有序」的场合。
