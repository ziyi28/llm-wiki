# 首页

这是一个 **LLM 维护的知识库**：用户提供来源和问题，LLM 负责写作、交叉引用和全部维护。模式详见 [[LLM-Wiki模式]]，运行约定见 [CLAUDE.md](../CLAUDE.md)。

## 入口

- [[index|内容目录]] —— 全部页面的分类清单
- [[log|日志]] —— 知识库演化时间线
- [[LLM-Wiki模式]] —— 本知识库遵循的核心模式
- [[LLM-Wiki模式文档]] —— 首个已摄入的来源

## 如何使用

1. **加资料**：把 markdown 文章/笔记放进 `raw/`，对 LLM 说「ingest 这个文件」。
2. **提问**：直接问，LLM 基于 wiki 作答；有价值的答案会沉淀到 `notes/`。
3. **看图谱**：打开 Obsidian 图谱视图，节点按类型着色——<span style="color:#E05252">红 = 来源</span>、<span style="color:#529BE0">蓝 = 概念</span>、<span style="color:#6BC26B">绿 = 实体</span>、<span style="color:#E0A052">橙 = 笔记</span>。
4. **定期体检**：对 LLM 说「lint 一下 wiki」。
