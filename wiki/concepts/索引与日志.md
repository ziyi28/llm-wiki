# 索引与日志

两个帮助 LLM（和用户）在 wiki 中导航的特殊文件，用途互补。

## index.md —— 内容导向

全库目录：每页一条（链接 + 一行摘要 + 可选元数据），按类别组织，每次 [[Ingest]] 后更新。[[Query]] 时 LLM **先读 index 找页面，再深入页面**——这个朴素方案在中等规模（约百个来源、数百页面）下效果出人意料地好，省掉了 embedding 检索基础设施。规模再大，可引入 [[qmd]] 这类真正的搜索引擎。

## log.md —— 时间导向

append-only 的事件记录：每次 ingest / query / lint 各记一笔。条目用固定前缀：

```
## [2026-04-02] ingest | 文章标题
```

于是简单 unix 工具即可解析——`grep "^## \[" log.md | tail -5` 列出最近 5 条。log 给用户一条 wiki 演化时间线，也帮 LLM 了解最近做过什么。
