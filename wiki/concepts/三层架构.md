# 三层架构

[[LLM-Wiki模式]] 的结构分三层：

## 1. 原始资料层（raw sources）

用户策展的来源收藏：文章、论文、图片、数据文件。**不可变**——LLM 只读不改。这是事实之源（source of truth）。本库对应 `raw/`。

## 2. Wiki 层

LLM 生成的 markdown 页面目录：摘要、实体页、概念页、比较、总览、综合。**LLM 全权拥有**：建页、随新来源更新、维护交叉引用、保持全库一致。用户读，LLM 写。本库对应 `wiki/`。

## 3. Schema 层

一份告诉 LLM「wiki 如何组织、遵循什么约定、按什么流程操作」的文档（Claude Code 用 CLAUDE.md，Codex 用 AGENTS.md）。它是让 LLM 成为**有纪律的 wiki 维护者**而非普通聊天机器人的关键配置，随使用与用户共同演化。本库对应根目录 `CLAUDE.md`。

## 信息流

`raw/`（用户放入，不可变）→ [[Ingest]] → `wiki/`（LLM 维护，持续更新）→ [[Query]] → 答案（有价值则回填 `wiki/notes/`）
